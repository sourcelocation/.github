# .github

Default community health files for every repository under this account that doesn't have its own: code of conduct, contributing guide and pull request template. These are deliberately free of CLA wording. Repositories that need a CLA carry their own copies, see the `repo-template` repository.

GitHub only reads this from a public repository named exactly `.github`.

It also holds what the repositories share: the release workflow they call (`.github/workflows/release.yml`) and `AGENTS.md`, how they all work.
